## 각 토픽 구성

- **핵심 한 줄** — 원어민이 실제로 쓰는 구분 기준
- **왜 헷갈리나** — 한국어·영어 화자가 걸려 넘어지는 지점
- **용법 정리** — 예문마다 음성 재생(보통 속도 / 느리게)
- **한눈에 비교** — 비교표 (총 190행)
- **흔한 실수** — ✗ 틀린 문장 → ✓ 올바른 문장 + 이유 (90개 사례)
- **암기 전략** — 규칙 암기 대신 기준 하나로 푸는 방법
- **확인 퀴즈** — 즉시 채점 + 해설 (총 116문항)
